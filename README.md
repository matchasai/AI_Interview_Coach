# IntervAI Coach Frontend

Frontend app for IntervAI Coach, built with React and Vite.

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- Framer Motion
- Axios

## Features

- Role/topic based mock interview sessions
- Instant evaluation with score, keywords, rubric, and model answers
- Re-check flow for edited answers
- Doubt session workspace with follow-up chat
- Progress dashboard and export options

## Local Setup

1. Install dependencies:
   - `npm install`
2. Create environment file:
   - copy `.env.example` to `.env`
3. Start dev server:
   - `npm run dev`

## Scripts

- `npm run dev` - start development server
- `npm run build` - production build
- `npm run lint` - run eslint
- `npm run preview` - preview production build

## Notes

- `.env` is gitignored.
- Keep secrets only in environment files.
