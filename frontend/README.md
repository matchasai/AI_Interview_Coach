# AI Interview Coach Frontend

Frontend application for AI Interview Coach.

## Stack

- React
- Vite
- Tailwind CSS

## Setup

1. Install dependencies:
	- `npm install`
2. Create environment file:
	- copy `.env.example` to `.env`
3. Run development server:
	- `npm run dev`

## Notes

- `.env` is ignored by git.
- Keep API keys and secrets only in local environment files.
